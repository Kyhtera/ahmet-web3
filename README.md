# Çarşamba Sofrası

Her çarşamba buluşan arkadaş grubunda yemeği kimin ısmarlayacağını takip eden tek sayfalık web uygulaması.

- Tek dosya: `index.html`. Kurulum ya da derleme gerekmez.
- Kayıtlar tarayıcının `localStorage`'ında tutulur. **Yedek** bölümünden JSON olarak yedeklenip geri yüklenebilir.

## Çalıştırma

`index.html` dosyasını tarayıcıda açman yeterli. Telefonda ana ekrana eklemek için bir adreste yayınlanmalı. Örneğin bu repoyu Vercel ya da GitHub Pages ile yayınlayabilirsin, derleme ayarı gerekmez.
